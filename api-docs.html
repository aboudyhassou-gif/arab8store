واجهة برمجة تطبيقات متاجر ALOSHI STORE

واجهة برمجة تطبيقات HTTP قائمة على الرموز المميزة، للمنتجات والطلبات

قاعدة واجهة برمجة التطبيقات

ORIGIN/client/api
جميع مسارات نقاط النهاية أدناه نسبية إلى هذه القاعدة.
تصفّح منتجات API
شوف كل المنتجات مع الـ ID الخاص فيها، وانسخه بضغطة وحدة

المصادقة

أرسل الترويسة التالية مع كل طلب:
api-token: YOUR_API_TOKEN
سيتم إرجاع الرمز 401/403 في حالة وجود رمز غير صالح/معطل أو عنوان IP غير مسموح به.

نقاط النهاية

طريقةطريقالوصف
GET/profileالحصول على بريدك الإلكتروني ورصيد محفظتك.
GET/productsقائمة المنتجات (تدعم الفلاتر).
GET/content/{categoryId}الحصول على فئة ومنتجاتها.
POST/GET/newOrder/{productId}
أو /newOrder/{productId}/params		إنشاء طلب (متكرر عبر order_uuid).
GET/check?orders=[...]&uuid=1التحقق من حالة الطلب بالمعرّفات أو UUID.

1) الملف الشخصي والتوازن

GETORIGIN/client/api/profile
إجابة
{ "status": "OK", "balance": "8788.683", "email": "email@example.com" }

2) المنتجات

GETORIGIN/client/api/products
الفلاتر:
  • ?products_id=52134,60321 — إرجاع معرّفات المنتجات هذه فقط (public_id)
  • ?base=1 — إرجاع id,name فقط
الحقل id هو معرّف ثابت وفريد يتولّد تلقائياً عند إنشاء المنتج ولا يتغيّر أبداً بعدها — آمن لربطه بأنظمة خارجية.
إجابة
[ { "id": "52134", "name": "UC 60", "price": 0.104, "params": ["Enter Player ID"], "category_name": "PUBG", "available": true, "qty_values": {"min":1,"max":15000}, "product_type": "amount", "parent_id": "10432" } ]

3) المحتوى (الفئة + المنتجات)

GETORIGIN/client/api/content/10432
إجابة
{ "status": "OK", "categories": [{"id":"10432","name":"PUBG"}], "products": [{"id":"52134","name":"UC 60","price":0.104, "...":"..."}] }

4) إنشاء ترتيب (متكرر)

POSTORIGIN/client/api/newOrder/{productId}
(أو /params)
المعلمات (الاستعلام أو نص الطلب):
  • qty — الكمية (يتم التحقق منها لكل نوع منتج)
  • playerId — مطلوب لبعض المنتجات
  • order_uuid — معرّف UUIDv4 الخاص بك لكل محاولة (مفتاح التكرار)
  • يتم قبول وتخزين أي معلمات مخصصة إضافية
إجابة
{ "status": "OK", "data": { "order_id": "ID_12345", "status": "processing", "price": 1.26048, "data": {"playerId": "test"}, "replay_api": ["CODE_IF_ANY"] } }

5) التحقق من الطلبات

باستخدام المعرّفات الرقمية:
GET ORIGIN/client/api/check?orders=[ID_123,ID_456]
بواسطة معرّفات UUID:
GET ORIGIN/client/api/check?orders=["YOUR_UUID"]&uuid=1
إجابة
{ "status": "OK", "data": [ { "order_id": "ID_123", "quantity": 1, "data": {"playerId": "test"}, "created_at": "2025-04-10 13:55:48", "product_name": "A-60UC-stock", "price": "1.260480", "status": "accept", "replay_api": ["erg3eg"] } ] }

أمثلة على استخدام cURL

curl -H "api-token: YOUR_API_TOKEN" \ "ORIGIN/client/api/products" curl -X POST -H "api-token: YOUR_API_TOKEN" \ "ORIGIN/client/api/newOrder/52134/params?qty=1&playerId=test&order_uuid=ecbdd545-e616-4aee-8770-7ee..."

مقتطفات سريعة من العملاء

جافا سكريبت (جلب البيانات)
async function getProducts() { const res = await fetch("ORIGIN/client/api/products", { headers: { "api-token": "YOUR_API_TOKEN" } }); if (!res.ok) throw new Error("HTTP " + res.status); return res.json(); }
PHP (cURL)
$ch = curl_init("ORIGIN/client/api/profile"); curl_setopt_array($ch, [ CURLOPT_RETURNTRANSFER => true, CURLOPT_HTTPHEADER => ["api-token: YOUR_API_TOKEN"] ]); $out = curl_exec($ch); curl_close($ch); echo $out;
جميع الاستجابات بتنسيق JSON. استخدم ترميز UTF-8 وأرسل رمزك المميز في رأس الطلب api-token.
