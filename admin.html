إعدادات الموقع

لوغو الموقع (يظهر بالشريط العلوي)

الأفضل: صورة PNG شفافة مستطيلة (مثل 300×80 px). لو ما في لوغو رح يظهر النص الافتراضي "ARAB STORE".

🔔 شعار الإشعارات (يظهر مع كل إشعار يصل للمستخدم)

هذه الصورة هي التي تظهر بجانب كل إشعار يصل لهاتف المستخدم حتى والموقع مغلق. الأفضل: صورة مربعة (مثلاً 512×512 px) بخلفية واضحة. بدون صورة مخصصة، يُستخدم شعار التطبيق ثم لوغو الموقع تلقائياً.

📱 أيقونة التطبيق (لما المستخدم يضيف الموقع للشاشة الرئيسية)

لازم تكون صورة مربعة (مثلاً 512×512 px) عشان تظهر منيح كأيقونة تطبيق على شاشة الموبايل، متل أي متجر منافس عندو أيقونة مميزة. بدون أيقونة مخصصة، رح يستخدم نفس اللوغو تلقائياً.

🖋️ لوغو المطوّر (تحت قائمة الـ3 نقاط فوق "برمجة وتصميم")

📲 تثبيت التطبيق (PWA)

اضغط الزر لتثبيت الموقع كتطبيق على جهازك.

سلايدر البانر الإعلاني (أعلى الصفحة الرئيسية)

0 / 5 صور
يدعم حتى 5 صور تتبدّل تلقائياً بسلايدر. المقاس المثالي: عريض (نسبة تقريبية 16:8) عشان يظهر بأفضل شكل بدون قص.

ربط واتساب + بوت الذكاء الاصطناعي

—
اربط رقم واتساب بالموقع عبر ربط جهاز (متعدد الأجهزة) — تظهرلك كود هنا، تدخله بجوالك من واتساب ← الأجهزة المرتبطة ← ربط جهاز ← الربط برقم الهاتف. بعد الربط، أي رسالة تجي للرقم يرد عليها البوت بالذكاء الاصطناعي ويفهم المتجر، ويحط رابط المتجر آخر كل رسالة.

إضافة مزوّد جديد

اترك الحقول التالية فاضية ليعمل مع شمس تلقائياً بلا أي إعداد. املأها فقط إذا كان مزوّدك يستخدم مسارات مختلفة عن نمط client/api.

📥 استيراد ملف منتجات مزوّد (CSV)

ارفع ملف المزوّد بصيغة id,name,price وسيتم: إنشاء/تحديث المزوّد، تقسيم المنتجات لأقسام تلقائياً، توليد صورة لكل منتج، إضافة هامش الربح، وربط كل باقة بالمزوّد. الصفوف غير المفهومة تُتخطّى تلقائياً.

مزوّدو شحن الألعاب (API)

استيراد تلقائي: بيسحب كامل كتالوج المزوّد (كل الأقسام والمنتجات) وينشئه بموقعك دفعة وحدة، ويطبّق هامش الربح يلي تحدده فوراً على كل الأسعار.

التسعير الذكي

💡 كيف بيشتغل؟

حدد فئة أو أكتر من الجدول تحت (فيك تحدد الكل أو فئات معيّنة بس)، حط نسبة الهامش يلي بدك ياها، واضغط "تطبيق". أي فئة مربوطة بمزوّد API رح يتحدّث سعرها فوراً = سعر المزوّد الحالي × (1 + الهامش%). وبعدين، النظام بيتحقق من سعر المزوّد تلقائياً مرة كل يوم ويحدّث السعر لحاله لو المزوّد غيّر سعرو.
