# موصل واتساب — ARAB STORE 💬

يربط رقم واتساب بالمتجر (وضع **ربط جهاز** / الأجهزة المتعددة) عبر مكتبة
[Baileys](https://github.com/WhiskeySockets/Baileys) غير الرسمية، ويوصّل الرسائل الواردة
إلى سيرفر المتجر على Vercel، ثم يرسل الرد الذي يولّده بوت الذكاء الاصطناعي.

> ⚠️ غير رسمي: يعتمد على واتساب ويب (الأجهزة المرتبطة). لا تستخدمه على رقمك الأساسي، بل رقم مخصّص للمتجر.

## الفكرة

```
[زبون] → واتساب → [هذا الموصل Baileys] → POST /api/wa/incoming (Vercel)
                                              ↓ (بوت AI + رابط المتجر)
[زبون] ← واتساب ← sendMessage ← الرد
```

سيرفر Vercel سيرفرلِس ولا يستطيع إبقاء اتصال واتساب مفتوحاً، لذلك:
- **الدماغ** (الذكاء + الإعدادات + السجل + الشحن) يعمل على **Vercel**.
- **الموصل** (هذا المجلد) يحتاج عملية مستمرة، فشغّله على استضافة مجانية.

## الإعداد

1. افتح لوحة الأدمن ← **بوت واتساب**، وانسخ قيمتين:
   - **رابط السيرفر** (`WA_SERVER`): مثال `https://your-store.vercel.app` (بدون `/api`).
   - **المفتاح السري** (`WA_SECRET`).
2. اختر طريقة التشغيل (تحت).
3. من لوحة الأدمن: اكتب رقم واتساب واضغط **ربط جهاز (طلب كود)**.
4. يأتيك **كود** في اللوحة → بجوالك: واتساب ← الأجهزة المرتبطة ← ربط جهاز ← **الربط برقم الهاتف** → أدخل الكود.
5. بعد الربط يصير 🟢 ويردّ البوت تلقائياً على الرسائل.

## طرق التشغيل المجانية

### 1) GitHub Actions (مجاناً — الأبسط)
- ارفع المشروع لمستودع GitHub.
- أضف Secret باسم `WA_SERVER` وآخر باسم `WA_SECRET` (Settings ← Secrets and variables ← Actions).
- شغّل الـ workflow **WhatsApp Connector** (يدوياً أول مرة للربط، ثم يعمل كل 6 ساعات).
- **مهم:** للمستودع العام دقائق غير محدودة. للمستودع الخاص حدّ 2000 دقيقة/شهر لا يكفي للتشغيل الدائم.

### 2) استضافة دائمة بـ Docker (Koyeb / Render / Fly / Hugging Face Spaces)
- ابنِ الصورة داخل مجلد `whatsapp-worker`:
  ```bash
  docker build -t arab-wa-worker .
  docker run -d --restart=always \
    -e WA_SERVER="https://your-store.vercel.app" \
    -e WA_SECRET="السر" \
    -e WA_RUN_MINUTES=0 \
    -v wa_auth:/data/.wa-auth \
    arab-wa-worker
  ```
- `WA_RUN_MINUTES=0` = تشغيل دائم بلا خروج.

### 3) تشغيل محلي (للتجربة)
```bash
cd whatsapp-worker
npm install
WA_SERVER="https://your-store.vercel.app" WA_SECRET="السر" npm start
```

## متغيرات البيئة
| المتغير | إلزامي | الوصف |
|---|---|---|
| `WA_SERVER` | ✅ | رابط المتجر (بدون `/api`) |
| `WA_SECRET` | ✅ | المفتاح السري من لوحة الأدمن |
| `WA_RUN_MINUTES` | ❌ | مدة التشغيل بالدقائق ثم الخروج (0 = دائم، افتراضي 350) |
| `WA_CREDS_DIR` | ❌ | مجلد حفظ الجلسة محلياً (افتراضي `./.wa-auth`) |
| `WA_LOG_LEVEL` | ❌ | مستوى السجلات (افتراضي `info`) |

## ملاحظات
- الجلسة (credentials) تُحفظ على السيرفر تلقائياً، فتبقى مرتبطة بعد إعادة التشغيل — لا حاجة لإعادة الربط.
- عند «فصل الجهاز» من اللوحة، يمسح الموصل جلسته ويمكنك الربط من جديد.
- للخروج قسرياً أثناء GitHub Actions أوقف التشغيل من تبويب Actions.
